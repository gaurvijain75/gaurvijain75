## 🚀 Projects

### 🚨 Real-Time Ambulance Corridor Clearance System
> Computer Vision • Deep Learning • Real-Time AI

A real-time traffic analysis system that detects and tracks vehicles using **YOLOv8** and **DeepSORT**, predicts vehicle trajectories 3-4 seconds ahead using an **Attention-based BiLSTM** model and classifies blockage threats from CRITICAL to LOW to automatically clear ambulance corridors. Achieves ~93.8% detection accuracy at 25+ FPS with under 100ms latency.

`Python` `YOLOv8` `DeepSORT` `BiLSTM` `Streamlit`

### 🌿 EcoAudit — Multimodal GraphRAG System for Carbon Footprint Analysis
> NLP • LLMs • Knowledge Graphs

An AI-powered SaaS platform that extracts carbon emission data from multimodal inputs — PDFs, images and audio — using **spaCy** and **LLMs**. Built a **Knowledge Graph** on **Neo4j** with **GraphRAG** for intelligent relationship-based querying and automated CBAM-compliant carbon emission report generation.

`Python` `spaCy` `Llama 3` `Whisper` `Neo4j` `GraphRAG`

### 🔐 GraphSAGE — Graph-Based Intrusion Detection System for IoT Networks
> Graph Neural Networks • Cybersecurity • IoT

A GNN-based intrusion detection system trained on the **UNSW-NB15** dataset that classifies malicious IoT network traffic as benign or malicious using **GraphSAGE**. Applied SMOTE and feature scaling to handle class imbalance, achieving **99.91% accuracy** and near-perfect ROC-AUC with strong cross-validated generalization.

`Python` `GraphSAGE` `GNN` `scikit-learn` `SMOTE`

### 📊 PSPLRAS — Student Performance & Learning Resource Analytics System
> Full-Stack Development • Machine Learning • Data Analytics

A full-stack web application that tracks student attendance, marks and academic records with **JWT authentication** and role-based access control. Includes a **scikit-learn** ML recommendation system using **K-Means clustering** and **cosine similarity** to deliver personalized learning resources, with a **Power BI** dashboard for performance analytics.

`Python` `FastAPI` `React.js` `MongoDB` `scikit-learn` `Power BI`

### 💼 FreelanceFlow — Intelligent Freelance Project Management & Bid Optimization Platform
> Full-Stack Development • Decision Systems • Cloud Deployment

A full-stack freelance project management platform built with **React.js** and **Spring Boot** RESTful APIs. Features a multi-criteria bid scoring engine ranking proposals using weighted factors like reliability, budget fit and experience match. Fully containerized and deployed using **Docker**.

`React.js` `Java` `Spring Boot` `MongoDB` `TypeScript` `Docker`
